SAMPLE COLLEGE STUDY GUIDE

HTML foundations:
HTML-1 through HTML-3

A quick review of the building blocks of web pages: document structure, text and links, and organized information.

WEB DEVELOPMENT3 TOPICSABOUT 10 MIN
HTML-1

Document structure and elements

HTML (HyperText Markup Language) describes the meaning and structure of content on a web page. Elements are written with tags and may contain text or other elements.

A basic document

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello, web!</h1>
    <p>This is a paragraph.</p>
  </body>
</html>
  • <!doctype html> tells the browser to use modern HTML.
  • <head> contains page information; <body> contains visible page content.
  • Headings express a hierarchy: use <h1> for the main heading, then <h2> for a subsection.
  • Most elements have an opening tag and a closing tag. Void elements, such as <meta> and <img>, do not wrap content.
Remember: HTML provides structure and meaning; CSS controls presentation, and JavaScript adds behavior.
HTML-2

Text, links, images, and lists

Use elements that describe their content. This helps people and browsers understand how parts of a page relate to each other.

<h2>Resources</h2>
<p>Visit the <a href="https://example.com">course site</a>.</p>
<img src="diagram.png" alt="A labeled diagram of a web page">
<ul>
  <li>Read the lesson</li>
  <li>Try the examples</li>
</ul>
  • Links use the <a> element and an href attribute to specify the destination.
  • Images use <img>. Write useful alt text describing the image's purpose; use empty alt text only when an image is decorative.
  • <ul> creates an unordered list; <ol> creates an ordered list. Each list item belongs in an <li>.
  • Attributes provide extra information in an opening tag. Their values are usually placed inside quotation marks.
Check yourself: If a link's destination changes, update its href. If an image conveys information, make sure its alt text communicates that information too.
HTML-3

Semantic sections, tables, and forms

Semantic elements communicate a section's role. Use tables for genuinely tabular data and forms to collect user input.

Page regions and a small data table

<header>Course title</header>
<main>
  <section>
    <h2>Weekly topics</h2>
    <table>
      <caption>Study schedule</caption>
      <tr><th>Week</th><th>Topic</th></tr>
      <tr><td>1</td><td>HTML</td></tr>
    </table>
  </section>
</main>
<footer>Course materials</footer>
  • <header>, <main>, <section>, and <footer> describe page regions. A page should have one main content area.
  • Tables organize data into rows and cells. Use <th> for header cells and <td> for data cells; do not use tables just to arrange a layout.
  • Forms collect input. Pair a <label> with a control using matching for and id values.

A labeled form control

<label for="topic">Topic to review</label>
<input id="topic" name="topic" type="text">
Accessibility tip: Semantic structure and explicit labels make a page easier to navigate with assistive technology and other browsing tools.
QUICK SELF-CHECK

Can you explain it without looking?

  1. What belongs in the <head> and what belongs in the <body>?
  2. How is an ordered list different from an unordered list?
  3. Why should an image have appropriate alt text?
  4. When should you use a table, and what is the purpose of a form label?

Suggested answers: The head holds document metadata and linked resources; the body holds page content. Ordered lists imply a sequence while unordered lists do not. Alt text communicates an informative image's meaning to people who cannot see it. Tables are for tabular data, and labels identify their form controls.
